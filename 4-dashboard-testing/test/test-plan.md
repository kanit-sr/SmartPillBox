# Test Plan

| ID | Flow | ขั้นตอน | ผลที่คาด | ผ่าน? |
|---|---|---|---|---|
| T01 | ล้ม → ยืนยัน | จำลองการล้มด้วยอุปกรณ์ทดสอบ ไม่กดยกเลิกภายใน 15 วิ ตรวจ alarm และ LINE จากนั้นเคลียร์ผ่าน dashboard ทำซ้ำอีกครั้งโดยเคลียร์ด้วยปุ่มกล่อง | ได้ fall_confirmed พร้อม hr, spo2, conf; กล่องมีไฟแดงและเสียงเตือน พร้อม LINE; เมื่อเคลียร์ได้ fall_acknowledged พร้อม by ตรงช่องทางและ after_s ตรงเวลาที่ผ่านไป ไฟ/เสียงเตือนล้มหยุด และ LINE แจ้งรับเหตุ | NOT RUN |
| T02 | ล้ม → กดยกเลิก | จำลองการล้ม แล้วกดปุ่มสั้นระหว่างนับถอยหลัง ก่อนครบ 15 วิ | กำไลหยุดสั่นและกลับโหมดปกติ ได้ fall_cancelled พร้อม conf; ไม่มี fall_confirmed ของเหตุเดียวกัน ไม่เปิด alarm กล่องและไม่ส่ง LINE | NOT RUN |
| T03 | SOS ค้าง 3 วิ | ขณะกำไลอยู่โหมดปกติ กดค้าง 3 วิแล้วปล่อยก่อนถึง 10 วิ | ได้ sos พร้อม hr, spo2; ข้ามการนับถอยหลัง 15 วิ กล่องเข้าสู่ fall_alarm และส่ง LINE แจ้ง SOS | NOT RUN |
| T04 | ถึงเวลากินยา → กิน | ตั้ง schedule ให้มีหลายมื้อ รอถึงมื้อทดสอบ ตรวจการเตือน จากนั้นให้เซนเซอร์พบคนและเปิดฝาค้างเกิน 2 วิภายใน 30 นาที | กล่องเตือนยา กำไลสั่น 3 ครั้งเมื่อได้รับ ACK ที่มี cmd bit0 ซึ่งอาจรอประมาณ 60 วิ; ได้ pill_taken พร้อม slot, late_min; last_pill_taken อัปเดต หยุดเตือนยา และไม่ส่ง LINE | NOT RUN |
| T05 | ลืมกินยา 30 นาที | รอถึงเวลากินยา ไม่ให้เซนเซอร์พบคนใน 10 นาทีแรก และไม่เปิดฝากินยาตลอด 30 นาที | ครบ 10 นาทีเข้าสู่การเตือนถี่ขึ้น; ครบ 30 นาทีได้ pill_missed พร้อม slot ตรงมื้อ หยุดเตือนยา และ LINE แจ้งลืมกินยา | NOT RUN |
| T06 | เน็ตหลุด → กลับมา | ตัดอินเทอร์เน็ตของกล่องโดยคง ESP-NOW ให้ทำงาน กระตุ้นเหตุการณ์และเก็บ log คิว จากนั้นต่ออินเทอร์เน็ตกลับ ทำซ้ำให้ครอบคลุม event ทุกชนิด; การเคลียร์ alarm ขณะ offline ใช้ปุ่มกล่อง | Event ผ่าน store_forward และถูกส่งครบหลังต่อกลับ โดยคง ts, id, d เดิม; ไม่มีเหตุใหม่จากการ retry; คิวระบายจนหมด; LINE ที่ต้องส่งย้อนหลังมีข้อความ “(ส่งช้า เกิดเมื่อ HH)” | NOT RUN |
| T07 | แบตต่ำ | ส่ง STATUS ด้วยแบต 20% จากนั้น 19% และส่งค่าต่ำซ้ำหลายรอบ | 20% ยังไม่เข้าเกณฑ์ต่ำกว่า 20%; ที่ 19% ได้ low_battery พร้อม batt; Shadow แสดงแบตตรงค่าที่ส่ง และ LINE แจ้งครั้งเดียวในช่วงแบตต่ำต่อเนื่อง | NOT RUN |
| T08 | กำไลขาดการติดต่อ | ให้กล่องรับ STATUS ก่อน จากนั้นหยุดส่ง STATUS โดยไม่ส่ง POWER_OFF รอเกิน 180 วิ แล้วคืนการส่ง STATUS | ได้ node_offline พร้อม last_seen; node_online=false และ LINE แจ้งขาดการติดต่อ; เมื่อรับ STATUS อีกครั้ง สถานะกำไลกลับออนไลน์ | NOT RUN |
| T09 | ปิดเครื่องกำไล | กดค้าง 10 วิ ตรวจว่ากล่องได้รับ POWER_OFF แล้วรอเกิน 180 วิ จากนั้นกดเปิดกำไลอีกครั้ง | ได้ node_power_off พร้อม batt; กำไลเข้า deep sleep; เมื่อกล่องรับ POWER_OFF แล้วต้องไม่แจ้งขาดการติดต่อจากการปิดครั้งนี้ และไม่ส่ง LINE สำหรับ node_power_off; เปิดใหม่แล้วส่ง STATUS ได้ | NOT RUN |
| T10 | ที่เก็บยาร้อน/ชื้น | ใช้เกณฑ์อุณหภูมิ ความชื้น และระยะเวลาค้างที่ทีมกำหนด ทดสอบอุณหภูมิเกินและความชื้นเกินแยกกัน แล้วคงค่าผิดปกติต่อเนื่อง | ได้ storage_warn พร้อม temp, hum ตรงค่าจริง; เมื่อไม่มี alarm อื่น กล่องแสดงไฟเหลืองและสถานะ storage_warn; LINE แจ้งครั้งเดียวในช่วงผิดปกติต่อเนื่อง | NOT RUN |
