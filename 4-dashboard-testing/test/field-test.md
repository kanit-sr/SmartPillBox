# การทดสอบต่อเนื่องและใช้งานจริง

สถานะ: NOT RUN เอกสารนี้เป็นแผน ยังไม่มีข้อมูลเก็บต่อเนื่อง 24 ชั่วโมง

โจทย์หน้า 7 ให้ Field Testing ระดับ 2 คะแนนเมื่อทดสอบต่อเนื่องในสภาพแวดล้อมของทีมและเก็บข้อมูลอย่างน้อย 24 ชั่วโมง ระดับ 3 คะแนนต้องทดสอบกับผู้ใช้จริงหรือสถานที่จริง ไม่ใช่ข้อบังคับผ่าน/ตกของ M5

## เตรียมรอบทดสอบ

1. เลือกช่วงอย่างน้อย 24 ชั่วโมงติดกัน สถานที่ ผู้รับผิดชอบ และ Run ID บันทึก commit/model/dashboard revision ด้วย [run template](evidence/RUN_TEMPLATE.md)
2. ตรวจ flow หลักบนโต๊ะก่อนเริ่ม ยืนยันการเก็บ Feed และ serial/MQTT log พร้อมพื้นที่จัดเก็บและ TTL
3. บันทึก schedule, interval ของ sensor/STATUS/Feed, threshold และวิธี sync เวลา ค่าที่เร่งเพื่อเดโมต้องคืนค่าปกติหรือระบุเป็นเงื่อนไขทดสอบ
4. ระบุแผนจ่ายไฟ/ชาร์จและช่วงที่กำไลไม่ได้สวม บันทึกการชาร์จหรือการเปลี่ยนแหล่งจ่าย ไม่อ้างว่ารันด้วยแบตเดียวทั้งวันหากมีการชาร์จกลางรอบ
5. นิยามความพร้อมเป็นเส้นทางแยก เช่น node → gateway และ gateway → dashboard กำหนด timeout ที่จะนับว่าขาดข้อมูลก่อนเริ่ม ไม่ใช้ “ไม่มี event ล้ม” เป็นหลักฐานว่าระบบหยุด

## ระหว่างรัน

- บันทึกสถานะเริ่มต้นและตรวจอย่างน้อยทุก 2 ชั่วโมงว่า logger ยังทำงาน เก็บ raw readings ต่อเนื่องแม้ไม่มี event
- บันทึกกิจกรรมปกติและปัญหาที่พบ เวลาเริ่ม/จบ outage, reconnect, restart, false positive และการแก้ไขหน้างาน
- ถ้าทำ fault injection เช่นตัด Wi-Fi ให้ทำเครื่องหมายเป็นช่วงทดสอบที่ตั้งใจแยกจากเหตุขัดข้องเอง
- กรณี logger เสียให้ระบุ unknown interval ห้ามเติมข้อมูลย้อนหลังให้เสมือนมีการวัดครบ ถ้าข้อมูลไม่ครบรอบที่ตั้งเป้า ให้รายงานข้อจำกัดและจัดรอบใหม่
- การทดสอบกับผู้ใช้จริงให้ระบุบริบทและงานที่ให้ลอง เช่น อ่านสถานะหรือรับเหตุ เก็บ feedback แบบไม่ระบุตัวตน ใช้อุปกรณ์ทดสอบสำหรับจำลองการล้มตาม T01

## ปิดรอบและตรวจหลักฐาน

1. บันทึกเวลาจบและระยะเวลาจริง export Feed ช่วงทั้งหมดพร้อมจำนวนจุด และเก็บ raw log
2. เทียบจำนวนข้อมูลที่ควรได้จาก interval กับที่ได้จริง โดยไม่แทน sample ที่หายด้วยค่าเดิม ตรวจ logger gap แยกจากระบบขัดข้อง
3. สรุป known-up, known-down, unknown ต่อเส้นทาง พร้อม downtime ยาวที่สุดและ recovery time ตาม [metrics](metrics.md)
4. อัปเดต issue และผลทดสอบที่ได้ตรวจจริงใน `test-results.md` การรันต่อเนื่องอย่างเดียวไม่ทำให้ทุก Test ID ผ่าน
